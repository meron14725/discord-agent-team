# ADR 0007: 外部エージェントスキルを検証済みスナップショットとして固定する

## Status

Accepted.

## Decision

会社の標準フローで使う外部スキルは、個人環境や実行時の最新版を直接共有しない。内容、出典、ライセンスをレビューしたコミットをスキルスナップショットとして会社基盤内に固定し、実行時はその内容だけを制御層からエージェントへ渡す。

初期版は `mattpocock/skills` のコミット `3cca18b368ae95cdbdebbff572ccafa662551015` と、`keitakn/engineering-skills` のコミット `b785a355ff83a10515a246026a0595a30ef41827` を採用する。いずれもMIT Licenseの表示と許諾文を同梱する。更新は差分、権限要求、外部通信、実行ファイル、ライセンスをレビューし、オーナー承認後に新しいスナップショットへ切り替える。

`grilling` が要求する事実調査と相談は既存の型付き内部実行へ置き換え、相談回数を制御層で強制する。`domain-modeling` の結果は制御層が要件Issueや承認済み成果物へ記録する。`explain-visually` は要件定義中の個別質問には使わず、要件Issueの完成後と実装計画のレビュー完了後にそれぞれ1回使う。GitHub取得、モデルによる構成、安全なHTML描画、Discord配布を分離し、モデルへGitHub資格情報やDiscord Botトークンを渡さない。Discordへ画像、短い説明、正本へのリンクを投稿し、安全化したHTMLと画像のハッシュを案件成果物として保存する。説明には利用者への価値、対象範囲と対象外、通常の流れ、権限とデータの境界、復元困難な変更、主な失敗経路、受入条件、ロールバック、未解決事項を含める。

## Consequences

上流スキルの改善は自動反映されず更新作業が必要になる。一方、同じ案件を同じ手順で再現でき、外部スキルの変更が会社規則や権限境界を暗黙に変えることを防げる。
