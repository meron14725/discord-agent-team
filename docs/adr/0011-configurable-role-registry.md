# ADR 0011: 専門役を設定可能な役割台帳で管理する

## Status

Accepted.

## Decision

専門役をコード上の固定分岐ではなく役割台帳へ登録する。台帳には責務、対応能力、利用可能なツール、禁止操作、入出力形式、相談可能な相手、並列区分、代替可能な役を含める。少なくとも10役を登録でき、統括は依頼ごとに必要な2〜4役を選ぶ。

初期構成は次の8役とする。

1. 統括
2. CTO: 要件定義、アーキテクチャ、技術調査、計画と実装のレビュー
3. UI・UX／フロントエンド
4. バックエンド／実装統合
5. QA・テスト
6. セキュリティ／情シス・SRE
7. 評価マネージャー
8. アナリスト

現在の4 Botは、統括、CTO、バックエンド／実装統合、セキュリティ／情シス・SREへ対応付ける。残り4役は設定と接続口を先に実装し、Discord Appの作成、トークン保存、サーバー追加が完了した役から一つずつ有効化する。Discordで会話する専門役は個別Botを使い、内部相談役はBotを持たない。

専門役間の依頼は制御層が型付きイベントとして配送する。Discordには実際のBot同士のメンション付き会話を表示するが、その表示を再び命令として取り込まない。

## Consequences

新しい専門役を追加するときにワークフロー本体の分岐を増やさずに済み、8役から10役以上へ拡張できる。役割の能力と権限が設定に集約されるため、台帳の変更は会社規則の変更としてレビューする必要がある。各役をDiscordへ表示するには個別のDiscord Appとトークンが必要になる。
