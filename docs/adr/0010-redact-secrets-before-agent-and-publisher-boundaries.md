# ADR 0010: 秘密情報をモデル入力と公開境界の前で遮断する

## Status

Accepted.

## Decision

Discordからモデルへ入力する前、およびGitHub、Discord、説明成果物へ出力する前に、トークン、秘密鍵、認証情報を決定論的な検査で検出する。検出した秘密値はモデル、Issue、ログ、成果物へ渡さない。誤検知を含めて自動的に処理を停止し、秘密値を除いた再入力を求める。

秘密情報を含むDiscordメッセージは、SREが漏えい拡大を止める緊急抑制として自動削除する。監査には投稿場所、時刻、検出種別、内容ハッシュ、削除結果だけを残し、元の値は残さない。オーナーへ該当する認証情報の失効と再発行を案内する。

秘密情報の検出器、監査出力、削除操作はモデルから分離した制御層に置く。モデルに削除権限やトークンを渡さない。

## Consequences

秘密情報がモデルや複数サービスへ複製される範囲を抑えられる。誤検知時にも元メッセージが削除されるため、監査メタデータと利用者への通知から再投稿を案内する必要がある。SRE Botには管理対象チャンネルでメッセージを削除できる権限が必要になる。
