# エージェント規則の管理

規則は適用範囲ごとに分ける。

| 種類 | 保存先 | 内容 |
|---|---|---|
| 会社共通規則 | `prompts/company-policy.md` | 全エージェントに必ず適用する安全、承認、連携、実行境界 |
| 会社の現状 | `prompts/company-memory.md` | 役割一覧、接続先、現在の構成など、判断に必要な共有事実 |
| 役割別規則 | `prompts/roles/<role>.md` | 担当範囲、専門的な判断基準、他役へ確認する条件 |

会社共通規則を先に適用し、役割別規則はその範囲内で補足する。役割別規則で会社共通規則を弱めたり上書きしたりしない。承認、権限、引き継ぎ回数など重要な境界はプロンプトだけでなく制御コードでも検査する。

次の基準で保存先を決める。

- 誰が担当しても守る必要がある規則は会社共通規則へ置く。
- 特定の職種だけが使う判断基準は、その役割別規則へ置く。
- 変わり得る組織情報や現在値は会社の現状へ置く。
- 破ると権限逸脱、承認回避、無限ループにつながる規則は制御コードにも実装する。

今回の「引き継ぎ先は元担当へ最大2往復まで確認でき、3往復目を始めない」は、全役に共通するため会社共通規則である。制御層も往復数、質問先、引き継ぎ深度を検査する。

起動時に会社共通規則、会社の現状、現在の全役割別規則を読み込む。必須ファイルの欠落、空ファイル、上限超過があれば起動を止める。これにより、一部のエージェントだけ古い規則で動く状態を避ける。
